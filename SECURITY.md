# Politique de sécurité

## Signaler une faille

Pour signaler une faille de sécurité, utiliser le signalement privé de GitHub :
onglet « Security » du dépôt, puis « Report a vulnerability ». Merci de ne pas
décrire la faille dans une issue ou une pull request publique.

## Ce qu'est ce projet

Ce dépôt est un projet d'apprentissage, maintenu par une seule personne. Les
signalements sont lus, mais aucun délai de réponse n'est garanti.

Seule la branche `main` est suivie.

La pile Docker Compose est une démonstration locale, pas un modèle de
production. Ses limites connues sont décrites dans le README.

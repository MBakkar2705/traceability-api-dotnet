# Interface web

Interface de lecture (lot 4a) de l'API de traçabilité : lots et leur parcours, fermes, stations. React, TypeScript, Vite et Tailwind CSS.

Lancer l'interface (l'API doit tourner dans un autre terminal) :

```powershell
npm install
npm run dev
```

Puis ouvrir `http://localhost:5173/`. Autres commandes : `npm run lint`, `npm run build`, `npm test`.

Le détail (écrans, adresses, limites connues, choix d'outils) est dans le [README du dépôt](../README.md), l'[ADR 0006](../docs/adr/0006-interface-web-vite-react.md), l'[ADR 0007](../docs/adr/0007-cors-dans-l-api.md) et [docs/verification.md](../docs/verification.md), section 11.
